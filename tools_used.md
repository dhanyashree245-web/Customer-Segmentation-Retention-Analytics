# Tools Used

## 1. Microsoft Power BI Desktop
Used to build the interactive customer segmentation and retention dashboard.

## 2. Power Query
Used to import and prepare customer, transaction, and support ticket datasets.

## 3. DAX (Data Analysis Expressions)
Used to create measures and calculated columns for sales, customer counts, retention analysis, and customer activity.

## 4. Data Modeling
Used to connect the Customers, Transactions, SupportTickets, and DateTable tables through relationships.

## 5. CSV
Used as the source format for the synthetic datasets.

## 6. Visual Studio Code
Used to create and edit project documentation.

## 7. GitHub
Used to publish the project files as portfolio evidence.
